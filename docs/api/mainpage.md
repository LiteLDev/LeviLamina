# API Reference

The C++ API of LeviLamina, generated from its headers: LeviLamina's own API in the `ll` namespace, and the
%Minecraft Bedrock Dedicated Server and client classes it exposes (the global namespace and `mce`, `Bedrock` …).
New to modding? Start with [Create your first mod](/LeviLamina/developer_guides/tutorials/create_your_first_mod/);
the [API Guides](/LeviLamina/api_reference/) explain each part of the API with examples.

## Browse

- [Namespaces](namespaces.html): every namespace, starting with `ll`, LeviLamina's API.
- [Class List](annotated.html) and the [Class Index](classes.html) (A–Z): every class, struct and union.
- [Class Hierarchy](hierarchy.html): the classes by inheritance.
- [Class Members](functions.html): every function, variable, type and enum value, by name.
- [File List](files.html): the headers, as they are laid out in the repository.

## Find something

Press <kbd>Ctrl</kbd> <kbd>K</kbd> (or <kbd>/</kbd>) to search the reference by name: classes, functions, variables,
types and files. The tree on the left lists the same pages; on phones it is in the menu.

## Where it comes from

The reference is built from the `src/` headers of the [LeviLamina repository](https://github.com/LiteLDev/LeviLamina)
on every change of the main branch. Functions marked *not yet publicly available* are part of %Minecraft but not
exported to mods yet: their documentation says how to request access.
